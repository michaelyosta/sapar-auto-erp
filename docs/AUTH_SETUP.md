# Вход и пользователи

## Локальный запуск

1. Запустите `npm run dev`.
2. Скопируйте одноразовый токен первичной настройки из вывода сервера Express. Токен появляется только если владелец ещё не создан и `SETUP_TOKEN` не задан вручную.
3. Откройте `http://127.0.0.1:5174`, введите имя, логин, пароль не короче 12 символов и токен. Первичная настройка создаёт владельца и сразу открывает сессию.
4. В разделе «Моя компания → Сотрудники» владелец или администратор может создать учётную запись, назначить базовую роль, отключить пользователя или задать новый временный пароль. Сотрудник обязан сменить временный пароль при первом входе.

Если сервер перезапустился до создания владельца, в dev-режиме он выдаст новый токен. После создания владельца первичная настройка недоступна.

## Роли прототипа

| Роль | Доступ |
| --- | --- |
| Владелец | Все реализованные разделы; управление всеми учётными записями и ролями |
| Администратор | Рабочие разделы; управление менеджерами и сотрудниками; не может назначать или менять другого администратора |
| Менеджер | Каталог, документы, проведение и отчёты; не может управлять пользователями |
| Сотрудник | Просмотр каталога/остатков, карточки клиентов и автомобилей, создание и проведение заказ-нарядов; не может просматривать финансовый дашборд и управлять пользователями |

Это базовая проектная матрица прав доступа. В последующих версиях матрица прав будет расширена дополнительными гранулярными правами по складам и кассам.

## Окружение перед развёртыванием

- В production задайте `NODE_ENV=production` и собственный секрет `SETUP_TOKEN` через защищённое хранилище конфигурации. Не записывайте секрет в репозиторий, интерфейс или логи.
- Используйте отдельный абсолютный `DB_PATH` на каждого клиента. Не размещайте одну SQLite-БД на нескольких приложениях одновременно.
- API по умолчанию слушает только `127.0.0.1`. Публичный доступ требует HTTPS reverse proxy. При TLS-терминации на локальном прокси задайте `TRUST_PROXY=loopback`; для другого окружения укажите конкретный доверенный IP/диапазон прокси. Не используйте `*` и не доверяйте заголовкам прокси от произвольных клиентов.
- Код пока не раздаёт production-сборку Vite через Express и не включает проверенную процедуру backup/restore. Этот документ описывает локальную настройку входа, а не готовую инструкцию развёртывания в production.
