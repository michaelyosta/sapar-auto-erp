# Архитектура Sapar Auto ERP

## 1. Общее описание системы

**Sapar Auto ERP** построена по модульной архитектуре с чётким разделением серверной бизнес-логики и клиентского интерфейса:

```
┌────────────────────────────────────────────────────────┐
│           Клиентский интерфейс (React 19 + Vite)       │
│  - Навигация по модулям ERP                            │
│  - Таблицы документов и аналитические отчёты           │
│  - POS-терминал розничной кассы                        │
│  - Формы печати официальных бланков                    │
└───────────────────────────┬────────────────────────────┘
                            │ REST API (JSON)
┌───────────────────────────▼────────────────────────────┐
│              Сервер приложений (Express.js)            │
│  - Аутентификация, сессии и ролевая модель (RBAC)      │
│  - Транзакционный движок проведения документов         │
│  - Автоматизация бизнес-процессов и триггеры           │
│  - Модули: Зарплата, Лояльность, Закупки, ЭСФ          │
└───────────────────────────┬────────────────────────────┘
                            │ SQLite API (Better-SQLite3)
┌───────────────────────────▼────────────────────────────┐
│                 База данных (SQLite 3 WAL)             │
│  - Хранение сумм в тиынах (целые числа)                │
│  - Партионный учёт запасов (FIFO / средняя с/с)        │
│  - Связи цепочек документов (Foreign Keys)             │
│  - Журнал аудита действий и файловое хранилище         │
└────────────────────────────────────────────────────────┘
```

## 2. Модели данных и финансовая точность

### Целочисленные финансовые расчеты
Для исключения ошибок округления с плавающей точкой все денежные величины в базе данных хранятся в **целочисленных тиынах** (`total_tiyin`, `unit_price_tiyin`, `paid_tiyin`):
$$\text{1 тенге (KZT)} = 100\text{ тиын}$$

Количественные показатели номенклатуры (товары, расходные материалы, технические жидкости) сохраняются в микро-единицах ($10^6$), что даёт абсолютную точность до 6 знаков после запятой при списании масел и смазок.

### Режим работы СУБД
* **WAL (Write-Ahead Logging):** Параллельное чтение без блокировки пишущих транзакций (`PRAGMA journal_mode = WAL`).
* **Foreign Keys:** Каскадные ограничения и целостность реляционных связей (`PRAGMA foreign_keys = ON`).

## 3. Серверные модули

1. **`server/index.ts`** — Инициализация сервера, подключение базы данных, маршрутизация базовых документов (заказы, накладные, акты).
2. **`server/auth.ts`** — Управление пользователями, аутентификация через сессионные cookie, хеширование `scrypt`, разграничение прав доступа (`owner`, `admin`, `manager`, `employee`).
3. **`server/payroll.ts`** — Расчёт сдельной заработной платы мастеров СТО: процент от стоимости выполненных работ и процент от маржи/оборота запчастей, оформление выплат через РКО.
4. **`server/discountsLoyalty.ts`** — Программа лояльности: эмиссия карт (`7700-XXXX-XXXX`), накопление баллов, персональные скидки.
5. **`server/procurement.ts`** — Модуль управления закупками: расчёт дефицита по страховым запасам (`min_stock_units`) и пакетное создание заказов поставщикам.
6. **`server/taxInvoices.ts`** — Электронные счета-фактуры: расчёт НДС 12%, симуляция регистрации в ИС ЭСФ с присвоением регистрационных номеров `ESF-KZ-...`.
7. **`server/automation.ts`** — Движок автоматизации: триггеры на смену статусов документов и дефицит остатков, генерация SMS-оповещений клиентам о готовности авто, задачи мастерам.
8. **`server/files.ts`** — Файловое хранилище с контролем дисковой квоты и привязкой файлов к документам и контрагентам.

## 4. Клиентские компоненты

* **`src/App.tsx`** — Корневой компонент: маршрутизация, адаптивная шапка, главное меню, карточки документов.
* **`src/DocumentsPage.tsx`** — Табличный журнал документов с интерактивным выдвижным фильтром и групповыми операциями (массовая смена статуса, проведение, экспорт в Excel/CSV).
* **`src/RetailPage.tsx`** — Кассовый POS-терминал с поддержкой кассовых смен, сплит-оплаты и быстрого подбора.
* **`src/FinanceReportsPage.tsx`** — Аналитические отчёты: ДДС (Cash Flow), ОПУ (P&L), Взаиморасчёты.
* **`src/TurnoverReportPage.tsx`** — Оборотно-сальдовая ведомость движения товаров.
* **`src/PayrollPage.tsx`** — Начисление и выплата зарплаты механикам.
* **`src/DiscountsPage.tsx`** — Управление скидками и бонусными баллами.
* **`src/PurchaseAnalyticsPage.tsx`** — Аналитика закупок и автозаказ.
* **`src/TaxInvoicesPage.tsx`** — Журнал счетов-фактур.
* **`src/SalesFunnelPage.tsx`** — Воронка ремонта и маржинальность мастеров.
* **`src/ScriptsPage.tsx`** — Настройка сценариев автоматизации и журнал запусков.
* **`src/FilesPage.tsx`** — Хранилище скан-копий, дефектовок и договоров.
* **`src/StartPage.tsx`** — Интерактивный чеклист запуска автокомплекса.
* **`src/PrintModal.tsx`** — Печать официальных бланков формата А4 с факсимиле и печатью.
