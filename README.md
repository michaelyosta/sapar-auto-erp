# Sapar Auto ERP

Полнофункциональная веб-система операционного учёта и автоматизации для автокомплексов, станций технического обслуживания (СТО), магазинов автозапчастей и автосервисов.

Система охватывает все бизнес-процессы авторемонтного предприятия: от первичного приёма автомобиля и оформления заказ-наряда до складского партионного учёта, расчёта сдельной оплаты труда мастеров, фискального учёта кассовых смен и управленческой финансовой отчётности.

---

## 🚀 Основные возможности

### 🚗 Заказ-наряды и CRM автосервиса
* **Оформление заказ-нарядов:** Привязка клиента, автомобиля, фиксация причины обращения, пробега при заезде и автоматический расчёт следующего сервисного интервала (ТО).
* **База автопарка:** Учёт автомобилей по госномеру, VIN, марке, модели и году выпуска. Прозрачная история всех ремонтов и заменённых узлов.
* **Цепочки документов:** Автоматическое создание связанных документов («Создать на основании»: Заказ-наряд $\rightarrow$ Отгрузка запчастей $\rightarrow$ Счёт $\rightarrow$ Оплата) с отслеживанием процента выполнения и оплаты.

### 📦 Склад и управление запасами
* **Партионный учёт:** Оприходование запасов, списание брака и потерь, внутреннее перемещение между складами.
* **Умная инвентаризация:** Автоматическое сопоставление фактических остатков с учётными с разделением расхождений на излишки и недостачи.
* **Резервирование:** Блокировка деталей под открытые заказы для исключения пересортицы.
* **Автозаказ снабжения:** Анализ дефицита запчастей на основе страховых запасов (`min_stock_units`) и автоматическое формирование заказов поставщикам.

### 💳 Розничная касса (POS)
* **Кассовый терминал:** Быстрый подбор запчастей и услуг, поиск по штрихкоду, комбинированная оплата (наличные с авто-расчётом сдачи + банковская карта / QR-код).
* **Кассовые смены:** Открытие смены с разменным фондом, закрытие смены (снятие Z-отчёта), автоматическая выписка приходных кассовых ордеров (ПКО) в главную кассу и безналичных платежей за вычетом эквайринговой комиссии.

### 👥 Сдельная заработная плата
* Расчёт выработки механиков и мастеров: индивидуальный процент от стоимости выполненных слесарных/диагностических работ и процент от оборота запчастей.
* Формирование расчетных ведомостей и автоматическая выплата через кассовые расходные ордера (РКО) или банк.

### 🎁 Программа лояльности и скидки
* Эмиссия бонусных карт клиентов, накопление бонусных баллов с оплат, частичная или полная оплата баллами, гибкие персональные скидки.

### 📊 Управленческая и финансовая отчётность
* **Движение денежных средств (Cash Flow):** Анализ поступлений и выплат по дням, кассам и банковским счетам, расчёт чистого денежного потока (Net Cash).
* **Прибыли и убытки (P&L):** Доходы, себестоимость списанных деталей (COGS), валовая прибыль, маржинальность и структура выручки.
* **Оборотно-сальдовая ведомость (Turnover):** Начальный остаток, приход, расход и конечное сальдо по всем номенклатурным позициям.
* **Взаиморасчёты:** Матрица дебиторской и кредиторской задолженностей.
* **Воронка продаж:** Анализ конверсии стадий ремонта, средний чек и рейтинг доходности мастеров.

### ⚡ Сценарии автоматизации
* Конструктор правил: событие-триггер (перевод заказ-наряда в статус «Готов», дефицит остатков, закрытие ремонта) $\rightarrow$ автоматическое действие (персонализированное SMS-оповещение автовладельцу, уведомление снабжения, создание задачи мастеру).
* Журнал выполнений и кнопка мгновенного тестового запуска правил.

### 📑 Официальные печатные формы
* Готовые бланки с адаптацией под А4: Заказ-наряд автосервиса с гарантийными обязательствами, Счёт на оплату с IBAN, Акт выполненных работ (Форма Р-1), Накладная на отпуск запасов (Форма З-2 / ТОРГ-12), Товарный чек.
* Возможность наложения факсимиле подписей руководителя, главного бухгалтера и оттиска синей печати.

## 🛠 Технологический стек

* **Frontend:** React 19, TypeScript, Vite, Lucide Icons.
* **Backend:** Node.js, Express, Better-SQLite3.
* **База данных:** SQLite в режиме WAL (`journal_mode = WAL`) со строгим контролем внешних ключей (`foreign_keys = ON`).
* **Точность финансовых расчётов:** Все валютные операции проводятся в целочисленных тиынах (`total_tiyin`, 1 KZT = 100 тиын). Количества хранятся в микро-единицах ($10^6$), гарантируя точность до 6 знаков после запятой без погрешностей округления IEEE 754.
* **Безопасность:** Ролевая модель доступа (`owner`, `admin`, `manager`, `employee`), хеширование паролей по стандарту `scrypt`, обязательная смена временного пароля, аудит действий пользователей.

## 🏁 Быстрый старт

### Требования
* Node.js версии 20+
* npm

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/michaelyosta/sapar-auto-erp.git
   cd sapar-auto-erp
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите проект в режиме разработки:**
   ```bash
   # Запуск бэкенда (порт 4300)
   npx tsx server/index.ts

   # Запуск фронтенда (порт 5176)
   npx vite --host 127.0.0.1 --port 5176
   ```

4. **Откройте приложение в браузере:**
   ```
   http://127.0.0.1:5176/
   ```
